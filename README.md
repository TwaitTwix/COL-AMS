# COL Attendance Management System

Attendance management for MCNP and ISAP, built with Express and Supabase.

Live website: https://col-ams.vercel.app

The application source and setup instructions are in
[attendance-monitoring-system](attendance-monitoring-system/README.md).

## Start locally

```powershell
cd attendance-monitoring-system
npm install
# For first-time setup only: copy .env.example to .env and add your own keys.
npm run local
```

On Windows you can also run `Start-Attendance-System.cmd` after installing dependencies and configuring the application.

Local credentials, environment files, and generated previews are excluded from Git.
